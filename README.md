# Statistical Analysis of Chocolate Sales Data

## Project Overview

This project is an individual undergraduate academic project
for the Applied Statistics CIE 3 assignment.

The project focuses on the statistical analysis of chocolate
sales data to identify patterns, relationships, and insights
using appropriate statistical techniques.

## Main Research Question

Is there an association between the quantity of chocolate sold
and total revenue?

## Project Objectives

1. Understand and prepare the chocolate sales dataset.
2. Classify variables according to their types and measurement scales.
3. Construct frequency tables and graphical representations.
4. Calculate descriptive statistical measures.
5. Examine the relationship between quantity sold and revenue.
6. Calculate and interpret Pearson's correlation coefficient.
7. Present findings in an academic statistical analysis report.

## Primary Statistical Analysis

The primary analysis will examine the association between:

- Independent variable: Quantity sold.
- Dependent variable: Revenue.

A scatterplot and Pearson's correlation coefficient
will be used to examine this relationship.

Correlation will not be interpreted as proof of causation.

## Final Results

The analysis was conducted using a simple random sample of 1,000
transactions. After data cleaning, 992 valid records were retained.

### Key Statistical Findings

- Cleaned sample size: 992 transactions.
- Quantity mean: 2.8901.
- Revenue mean: 24.3781.
- Pearson correlation coefficient: r = 0.7425.
- Coefficient of determination: R² = 0.5513.
- Approximately 55.13% of the variation in revenue is explained
  by the fitted linear relationship with quantity.

### Interpretation

The results indicate a strong positive association between
quantity sold and revenue. However, correlation does not establish
causation.
